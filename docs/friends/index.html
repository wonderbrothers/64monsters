Myフレンド

人から受け取ったコードに、自分がわかる名前をつけて残しておくページです。 登録しておくと、その人との相性をいつでも見られます。

フレンドを登録

相手に、結果ページ（その人のタイプのページ）の「鑑定コード」をコピーして送ってもらってください。 タイプコード（例：ENTP-A-H）だけでも登録できます。 相性を見るのはどちらでも同じです。鑑定コードなら、その人が受けた日も一緒に残ります。

名前はこの端末の中だけに残ります（鑑定コードそのものに名前は入っていません）。 同じ名前で登録し直すと、その人の内容が新しいほうに入れ替わります。

まだ誰も登録されていません。

名前と、鑑定コードまたはタイプコード（例：ENTP-A-H）を入れると登録できます。自分の鑑定コードを相手に渡したいときは、自分の結果ページでコピーできます。

登録したフレンド

    自分の結果ページを開く 相性をくわしく見る

    登録した名前と鑑定コードは、お使いのブラウザの中にのみ保存しています。サーバーには送っていません。 相手にも、こちらにも、誰が誰を登録したかは伝わりません。

    他の人の情報を預かることになります。名前は本名である必要はありません。 共有の端末では登録を控えるか、使い終わったら削除してください。

    Safari（iPhone・iPad・Mac）では、7日間このサイトを開かないと登録が消えます。 ブラウザ側の仕様で、こちらで防ぐ方法はありません。

    鑑定コードの写し間違い・途中で切れたものは検査符号で見つけられますが、 本気の改ざんは防げません。相手が本当にその結果だったかまでは保証できません。 タイプコードだけの登録には、そもそも検査するものがありません。
