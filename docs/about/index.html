何を送っていて何を送っていないか、どうやって作ったか、結果をどう受け取ってほしいか。 隠さずに書いておきます。

回答とデータの扱い

90問の回答はサーバーに送信していません。採点もお使いのブラウザの中だけで行っています。「保存して中断」した回答、マイタイプの登録、ヒストリー、Myフレンドに登録した名前とコード、表示設定も同じで、すべてブラウザ内（localStorage）にのみ保存しています。

フレンドの名前は、あなたがご自分で付けたものです。鑑定コードそのものに名前は入っていません。他の方の情報をお預かりすることになるため、本名である必要はありませんし、共有の端末では登録を控えることをおすすめします。こちらから相手に知らせることはありませんし、こちらにも届きません。

そのため、保存したものは次の場合に失われます。

  • ブラウザのデータ（サイトデータ・履歴）を消したとき
  • プライベートモードで受けたとき（そのウィンドウを閉じた時点で消えます）
  • 別の端末・別のブラウザで開いたとき（そちらには引き継がれません）
  • Safari（iPhone・iPad・Mac）で、7日間このサイトを開かなかったとき

最後のものは補足が必要です。Safari には、ブラウザを使った日数で7日のあいだ、そのサイトに対する操作（タップ・クリック・入力）が一度もないと、サイトが保存したデータをすべて削除するという仕様があります。こちらで防ぐ方法はありません。Chrome や Firefox にこの動作はありません。

記録を長く残したい場合は、ヒストリーのページから JSONで書き出して手元に保存してください。消えてしまっても、そのファイルを読み込めば元どおりになります。端末を移すときも同じ手順で引き継げます。

外部への通信

このサイトが外部に接続するのは次の2つだけです。広告のタグは入れていません。

  • Webフォント（Google Fonts）の読み込み
  • アクセス解析（Google アナリティクス）のタグ

アクセス解析に送っているのは、どのページが見られたか、診断を始めて終えたか、何問目まで進んだか、何秒かかったかです。個々の設問への回答は送っていません。

ただし、結果ページのURLにはタイプが含まれます（例：/t/ENTP-A-H/）。閲覧されたページとして記録されるため、結果として「どのタイプが出たか」は匿名の集計に含まれます。設問ページ（/quiz/）とヒストリー（/history/）は検索エンジンには載せていません。

どうやって作ったか

キャラクター画像と解説文は生成AIを用いて制作しています。実在の人物・団体とは関係がなく、描写に不自然な点が含まれる場合があります。

本診断はユング心理学の類型論を参考にした独自のものです。心理検査ではありません。特定の心理検査や既存の性格診断サービスとは関係がなく、その名称・タイプ呼称・解説文も使用していません。設問・タイプ名・解説文・キャラクターはすべて独自に制作したものです。

6つの軸のうち4つはよく知られた枠組みを参考にし、そこに自分への確信（A / O）と人への構え（H / C）の2軸を加えています。各軸15問・全90問で、どの軸にも逆転項目を7〜8問ずつ入れているため、すべて同じ側に答えても偏りません。

結果の受け取り方

結果は、回答した時点の自己認識を整理したものです。人の性格は状況や時期によって変わります。自分を知る手がかりとして扱い、可能性を狭める枠としては使わないでください。

同じ人が受け直すと数値は動きます。それは誤りではなく、その軸が状況に左右されやすいということです。ヒストリーで振れ幅を見ると、どこが自分の芯で、どこが揺れる部分なのかが分かります。

相性ページのスコアについて。6軸のうち、その関係で追い風になる軸の重みが全体の何割かを表しています。この重みは測定値ではなく、こちらで設計したものです。低い数値は「相性が悪い」ではなく「放っておくとずれる部分が多い」という意味で読んでください。

採用選考など、人の評価や選抜には使わないでください。そのための妥当性の検証をしていません。
