H（信頼）とC（慎重）の違い

64タイプの6文字目にあたる軸です。人にまず開くか、見きわめてから近づくかを見ています。どちらが社交的か、という軸ではありません。

2つの極

H・信頼

まず信じて、自分から開いていく

  • 初対面でも、先に自分のことを話せる
  • 頼まれごとを、相手を測らずに引き受ける
  • 裏切られてからでないと、疑わない

C・慎重

見きわめてから、距離を縮める

  • 相手を見てから、出す情報の量を決める
  • 打ち解けるまでに時間がかかると言われる
  • 信用した相手にだけ、急に深く関わる

よくある誤解

Cは「人が嫌い」でも「内向的」でもありません。開く相手を選んでいる、という意味です。外向型（E）でC、内向型（I）でHの人はふつうにいます。人と会う量の話ではなく、会った人にどこから入るかの話です。

同じ4文字で、HとCを並べる

この軸が変わると、同じ基本タイプでも呼び名が変わります。もう一方の軸はAに固定して並べました。

よくある質問

HとCは何が違いますか？

人への構えの軸です。H（信頼）はまず信じて、自分から開いていく。C（慎重）は見きわめてから、距離を縮める。どちらが優れているという軸ではありません。

Cであることは弱点ですか？

Cは「人が嫌い」でも「内向的」でもありません。開く相手を選んでいる、という意味です。外向型（E）でC、内向型（I）でHの人はふつうにいます。人と会う量の話ではなく、会った人にどこから入るかの話です。

自分がどちらか分かりません

90問の診断で判定できます。差が3以内のときは「立っていない」として扱い、どちらとも決めつけない形で表示します。

自分がHとCのどちらかは、90問に答えると出ます。

90問の診断を受ける

全90問・約10分。登録は不要で、回答はブラウザの中だけで採点します。

同じ人でも、受けるたびに数値は動きます。

もう一度受ける

受けた回ぶんの記録は ヒストリー に残ります。前回との差を見ると、どの軸が自分の芯で、どの軸が状況で揺れるのかが分かります。
