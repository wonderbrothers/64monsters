ENFP-O-H とは

ENFP-O-H（ENFP-OH／ENFP OH）は、ベースコード ENFP に、独自軸のO（揺らぎ）とH（信頼）が重なるタイプです。64モンスターズでは「揺れる火つけモンスター」と呼んでいます。

好奇心の幅が広く、人にもアイデアにも遠慮なく飛び込みます。その場を明るくし、停滞した状況に風を入れる存在です。熱の立ち上がりが速いぶん、持続の設計が課題になります。

人の話にも自分の思いつきにも影響されて、行き先が日々変わるタイプ。誰のことも疑わず、自分の判断も疑うので、可能性がどこまでも開いていきます。一緒にいると楽しい人ですが、本人のなかでは常に選べない苦しさが続いています。

ENFP-A-H との違い

どちらも人を疑わずに飛び込み、誰とでもすぐ打ち解けます。ENFP-O-H は人の話を聞くたびに行き先を描き直し、ENFP-A-H は一度ついた火をそのまま走らせます。O-H は案が人の数だけ広がり、A-H は動きだしが速い。決めきれずに困るのは O-H です。

ENFP-O-C との違い

どちらも思いついたことを自分のなかで何度も疑います。ENFP-O-H はその揺れを人の前でそのまま見せ、ENFP-O-C は話す相手を選んで内側で温めます。O-H は相談した人の数だけ行き先が増え、O-C は誰にも出していない案が溜まっていきます。

ENFP-O-H の強みと、気をつけたいところ

強み

人の考えを取り込むことに抵抗がない。人が混ざるほど良くなる企画に、いちばん向いています。

  • 迷っている途中を見せられるので、周りが気軽に口を挟みやすい
  • 誘われた場をその場で本気で楽しみ、誘った相手を後悔させない
  • 考えが変わることを恐れず、間違いに気づいたら素直に引き返せる

落とし穴

選べないまま時間だけが過ぎる。決める日を人と約束してしまう——自分ひとりで決めようとしないのが、いちばん早い解決です。

  • 相談した相手ごとに違う返事をして、あとで話が食い違う
  • 相手の期待に応えたくて、できるか分からない約束まで受けてしまう
  • 誰にでも開くぶん、知り合いの数に比べて続く関係が少ない

ENFP-O-H がつまずきやすい場面

  1. 週末の予定を三人から誘われ、その場ではどれにも「行きたい」と答えて、前日に二つを断る連絡を書いている。

    誘われたその場では「予定を見て今夜返す」とだけ言う。行きたい気持ちと、行ける予定を分けて扱えるようになります。

  2. 企画会議で出る意見に毎回うなずいているうちに、翌週には自分が何を提案していたのか説明できなくなっている。

    会議の前に、自分の案を一行で書いて手元に置いておく。人の意見を混ぜるときに、戻る場所になります。

  3. 家族に「この前と言っていることが違う」と言われ、どちらも本心だったのに、うまく説明できない。

    考えが変わったときは「前はこう思っていたけど、いまはこう」と、前の考えから話す。変わった道筋が見えると、相手は振り回されたと感じにくくなります。
