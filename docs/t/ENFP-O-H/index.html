ENFP-O-Hとはどんなタイプですか？

ENFP-O-Hは「揺れる火つけモンスター」です。64モンスターズが90問の回答から分類する64タイプのひとつで、ベースコードENFPに、独自軸のO（揺らぎ）とH（信頼）が重なります。人の話にも自分の思いつきにも影響されて、行き先が日々変わるタイプ。誰のことも疑わず、自分の判断も疑うので、可能性がどこまでも開いていきます。一緒にいると楽しい人ですが、本人のなかでは常に選べない苦しさが続いています。

ENFP-O-Hの「O」は何を表していますか？

Oは、64モンスターズが独自に加えている「自分への確信」の軸です。O＝揺らぎで、決めたあとも考え直し、揺れながら精度を上げるという意味です。もう一方の極はA（確信）で、この1文字が変わると同じベースコードでも現れ方が変わります。

ENFP-O-Hの「H」は何を表していますか？

Hは、64モンスターズが独自に加えている「人への構え」の軸です。H＝信頼で、まず信じて、自分から開いていくという意味です。ベースコードとは別に判定するので、どのベースコードの人にもHとCの両方がいます。

ENFP-O-Hと同じENFPベースコードのタイプには何がありますか？

ENFP-A-H、ENFP-A-C、ENFP-O-H、ENFP-O-Cの4つです。ベースコードは同じで、独自軸の A / O（自分への確信）と H / C（人への構え）の組み合わせだけが違います。ENFP-O-HはO（揺らぎ）とH（信頼）、ENFP-A-HはA（確信）とH（信頼）です。

ENFP-O-Hと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはENFP-A-H、ESFP-A-H、INFP-A-H、仕事のパートナーとしてはISTP-A-H、ESTP-A-H、ISFP-A-H、友人としてはENTP-A-H、ENFP-A-H、ENTP-O-Hが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。設計した重みによる目安で、測定値ではありません。
