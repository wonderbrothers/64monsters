ENTJ-O-C とは

ENTJ-O-C（ENTJ-OC／ENTJ OC とも書かれます）は、64タイプ性格診断のうちの1つです。ENTJの4文字に、自分への確信を表すO（揺らぎ）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「静かに練る推進モンスター」と呼んでいます。

ゴールを定め、そこへ人と資源を集めて到達させる推進力があります。停滞そのものを損失と捉えるため、決断は速く、責任も引き受けます。要求水準が高く、それを他者にも自然に求めます。

人に見せないところで検討を重ね、決めたら一気に動くタイプ。自分の案を何度も疑い、しかも途中の状態を見せないので、周囲には長い停滞に映ります。判断の外れは少ないのですが、その静けさが、待つ側には不安として伝わります。

よくある質問

ENTJ-O-Cとはどんなタイプですか？

ENTJ-O-Cは「静かに練る推進モンスター」です。目標を掲げ、人と資源を動かして届かせる人というENTJの性質に、自分への確信がO（揺らぎ）、人への構えがC（慎重）の組み合わせが重なります。人に見せないところで検討を重ね、決めたら一気に動くタイプ。自分の案を何度も疑い、しかも途中の状態を見せないので、周囲には長い停滞に映ります。判断の外れは少ないのですが、その静けさが、待つ側には不安として伝わります。

ENTJ-O-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはENTJ-A-C、ESTJ-A-C、INTJ-A-C、仕事のパートナーとしてはISFJ-A-C、ESFJ-A-C、ISTJ-A-C、友人としてはENFJ-A-C、ENTJ-A-C、ENFJ-O-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

ENTJ-O-Cの「O」と「C」は何を表していますか？

Oは自分への確信の軸で、揺らぎ＝決めたあとも考え直し、揺れながら精度を上げるという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じENTJでも、この2文字が変わると現れ方が変わります。

ENTJ-O-Cは「ENTJ-OC」や「ENTJ OC」と同じですか？

同じものです。ENTJ-O-C・ENTJ-OC・ENTJ OC・ENTJ O C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。
