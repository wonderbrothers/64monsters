ENTJ-O-C とは

ENTJ-O-C（ENTJ-OC／ENTJ OC）は、ベースコード ENTJ に、独自軸のO（揺らぎ）とC（慎重）が重なるタイプです。64モンスターズでは「静かに練る推進モンスター」と呼んでいます。

ゴールを定め、そこへ人と資源を集めて到達させる推進力があります。停滞そのものを損失と捉えるため、決断は速く、責任も引き受けます。要求水準が高く、それを他者にも自然に求めます。

人に見せないところで検討を重ね、決めたら一気に動くタイプ。自分の案を何度も疑い、しかも途中の状態を見せないので、周囲には長い停滞に映ります。判断の外れは少ないのですが、その静けさが、待つ側には不安として伝わります。
