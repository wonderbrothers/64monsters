INFP-O-C とは

INFP-O-C（INFP-OC／INFP OC とも書かれます）は、64タイプ性格診断のうちの1つです。INFPの4文字に、自分への確信を表すO（揺らぎ）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「沈黙の空想モンスター」と呼んでいます。

何が正しいかより「何を大切にしたいか」で動きます。内面世界が豊かで、言葉やイメージにこだわります。譲れない一線に触れられたときだけ、驚くほど頑固になります。

内側に広い世界を持ちながら、その入口を誰にも見せないタイプ。自分の感じ方を疑い続け、人にも簡単には開かないので、外からは静かな人としか映りません。言葉にならないものを言葉にする作業を、ひとりで延々と続けています。

よくある質問

INFP-O-Cとはどんなタイプですか？

INFP-O-Cは「沈黙の空想モンスター」です。自分の価値観に、正直であろうとする人というINFPの性質に、自分への確信がO（揺らぎ）、人への構えがC（慎重）の組み合わせが重なります。内側に広い世界を持ちながら、その入口を誰にも見せないタイプ。自分の感じ方を疑い続け、人にも簡単には開かないので、外からは静かな人としか映りません。言葉にならないものを言葉にする作業を、ひとりで延々と続けています。

INFP-O-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはINFP-A-C、ISFP-A-C、ENFP-A-C、仕事のパートナーとしてはESTP-A-C、ISTP-A-C、ESFP-A-C、友人としてはINTP-A-C、INFP-A-C、INTP-O-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

INFP-O-Cの「O」と「C」は何を表していますか？

Oは自分への確信の軸で、揺らぎ＝決めたあとも考え直し、揺れながら精度を上げるという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じINFPでも、この2文字が変わると現れ方が変わります。

INFP-O-Cは「INFP-OC」や「INFP OC」と同じですか？

同じものです。INFP-O-C・INFP-OC・INFP OC・INFP O C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。
