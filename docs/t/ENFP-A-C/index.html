ENFP-A-C とは

ENFP-A-C（ENFP-AC／ENFP AC とも書かれます）は、64タイプ性格診断のうちの1つです。ENFPの4文字に、自分への確信を表すA（確信）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「見極める火つけモンスター」と呼んでいます。

好奇心の幅が広く、人にもアイデアにも遠慮なく飛び込みます。その場を明るくし、停滞した状況に風を入れる存在です。熱の立ち上がりが速いぶん、持続の設計が課題になります。

熱を持ちながら、それをどこへ注ぐかを慎重に選ぶタイプ。直感に迷いはないのに、相手や場を見きわめるまで動かないので、外からは冷静な企画者に見えます。当たりの精度は高い代わりに、内側の熱量が周囲に伝わりません。

よくある質問

ENFP-A-Cとはどんなタイプですか？

ENFP-A-Cは「見極める火つけモンスター」です。人とアイデアを出会わせて、熱を起こす人というENFPの性質に、自分への確信がA（確信）、人への構えがC（慎重）の組み合わせが重なります。熱を持ちながら、それをどこへ注ぐかを慎重に選ぶタイプ。直感に迷いはないのに、相手や場を見きわめるまで動かないので、外からは冷静な企画者に見えます。当たりの精度は高い代わりに、内側の熱量が周囲に伝わりません。

ENFP-A-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはENFP-O-C、ESFP-O-C、INFP-O-C、仕事のパートナーとしてはISTP-O-C、ESTP-O-C、ISFP-O-C、友人としてはENTP-O-C、ENFP-O-C、ENTP-A-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

ENFP-A-Cの「A」と「C」は何を表していますか？

Aは自分への確信の軸で、確信＝自分の判断を疑わず、迷いが短いという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じENFPでも、この2文字が変わると現れ方が変わります。

ENFP-A-Cは「ENFP-AC」や「ENFP AC」と同じですか？

同じものです。ENFP-A-C・ENFP-AC・ENFP AC・ENFP A C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。

ENFP-A-C は診断結果の1つです。自分がどのタイプかは、受けてみると分かります。
