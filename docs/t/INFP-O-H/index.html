INFP-O-H とは

INFP-O-H（INFP-OH／INFP OH）は、ベースコード INFP に、独自軸のO（揺らぎ）とH（信頼）が重なるタイプです。64モンスターズでは「心が波打つ空想モンスター」と呼んでいます。

何が正しいかより「何を大切にしたいか」で動きます。内面世界が豊かで、言葉やイメージにこだわります。譲れない一線に触れられたときだけ、驚くほど頑固になります。

感じたことがそのまま表に出て、しかも相手の感情まで受け取ってしまうタイプ。自分の判断を何度も疑い、人のことは疑わないので、日によって見えている世界がまるで違います。豊かさと不安定さが、同じ一つの性質から来ています。

INFP-A-H との違い

どちらも人を信じて開きます。違うのは、自分の感じ方をどれだけ信じるかです。INFP-A-H は大切なものを迷いなく語り、INFP-O-H は同じものを抱えながら、その日の揺れも一緒に見せます。A-H は言葉がまっすぐ届き、O-H は相手の気持ちに寄り添う深さが出ます。

INFP-O-C との違い

どちらも自分の感じ方を疑い続けます。INFP-O-H はその揺れが表に出て人にも伝わり、INFP-O-C は内側に抱えたまま外には見せません。周りから見ると、O-H は気持ちが分かりやすい人、O-C は静かで読みにくい人です。

INFP-O-H がつまずきやすい場面

  1. 作ったものに否定的な感想が一つだけつき、ほかの好意的な感想が目に入らなくなる。

    感想は届いた日に全部読まず、翌日にまとめて読むと決めておく。一晩置くと、言葉の重さが元の大きさに戻ります。

  2. 一緒にいる人の機嫌が悪いと、理由を聞く前に自分のせいだと思い込む。

    「何かあった？」と短く聞いてしまうほうが、ひとりで抱えるより早く楽になります。たいていは自分と関係のない理由です。

  3. 昨日は良いと思っていた計画が、今朝は全部だめに見えて手をつけられない。

    気分が変わった日には計画を捨てない、と決めておく。判断は、気持ちが落ち着いた日にやり直せば間に合います。
