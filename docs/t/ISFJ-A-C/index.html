ISFJ-A-C とは

ISFJ-A-C（ISFJ-AC／ISFJ AC とも書かれます）は、64タイプ性格診断のうちの1つです。ISFJの4文字に、自分への確信を表すA（確信）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「見守るお世話モンスター」と呼んでいます。

相手が困る前に手当てをしておく、静かな献身のタイプです。記憶が細かく、人の好みや事情をよく覚えています。頼まれると断りにくく、負担が偏りやすいのが弱点です。

手を出す前に、相手が本当に困っているかを見きわめるタイプ。助けると決めたら迷いませんが、押しつけになることを避けるので、動くまでに一拍あります。過不足のない支え方ができる一方、支えていること自体に誰も気づきません。

よくある質問

ISFJ-A-Cとはどんなタイプですか？

ISFJ-A-Cは「見守るお世話モンスター」です。気づかれないところで、支えを差し出す人というISFJの性質に、自分への確信がA（確信）、人への構えがC（慎重）の組み合わせが重なります。手を出す前に、相手が本当に困っているかを見きわめるタイプ。助けると決めたら迷いませんが、押しつけになることを避けるので、動くまでに一拍あります。過不足のない支え方ができる一方、支えていること自体に誰も気づきません。

ISFJ-A-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはISFJ-O-C、INFJ-O-C、ESFJ-O-C、仕事のパートナーとしてはENTJ-O-C、INTJ-O-C、ENFJ-O-C、友人としてはISTJ-O-C、ISFJ-O-C、ISTJ-A-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

ISFJ-A-Cの「A」と「C」は何を表していますか？

Aは自分への確信の軸で、確信＝自分の判断を疑わず、迷いが短いという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じISFJでも、この2文字が変わると現れ方が変わります。

ISFJ-A-Cは「ISFJ-AC」や「ISFJ AC」と同じですか？

同じものです。ISFJ-A-C・ISFJ-AC・ISFJ AC・ISFJ A C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。
