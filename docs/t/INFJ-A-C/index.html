INFJ-A-C とは

INFJ-A-C（INFJ-AC／INFJ AC とも書かれます）は、64タイプ性格診断のうちの1つです。INFJの4文字に、自分への確信を表すA（確信）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「静かな確信の洞察モンスター」と呼んでいます。

この INFJ という4文字は、64モンスターズ独自の設問と採点による結果を表すものです。ほかの性格検査による判定を示すものではありません。コードの読み方

人の感情や場の力学を、本人より早く察知します。理想が高く、それを静かに、しかし粘り強く形にしようとします。内側は激しく動いていても、外からは穏やかに見えるのが特徴です。

同じ確信を持ちながら、それを外に出す相手を厳しく選ぶタイプ。察知の速さと判断の揺るぎなさを、静けさの下に隠しています。頼られたときにだけ深く関わるので、信頼された相手からは絶大に頼られ、それ以外の人からは何も見ていないように扱われます。

よくある質問

INFJ-A-Cとはどんなタイプですか？

INFJ-A-Cは「静かな確信の洞察モンスター」です。言葉になる前のものを、先に感じ取る人というINFJの性質に、自分への確信がA（確信）、人への構えがC（慎重）の組み合わせが重なります。同じ確信を持ちながら、それを外に出す相手を厳しく選ぶタイプ。察知の速さと判断の揺るぎなさを、静けさの下に隠しています。頼られたときにだけ深く関わるので、信頼された相手からは絶大に頼られ、それ以外の人からは何も見ていないように扱われます。

INFJ-A-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはINFJ-O-C、ISFJ-O-C、ENFJ-O-C、仕事のパートナーとしてはESTJ-O-C、ISTJ-O-C、ESFJ-O-C、友人としてはINTJ-O-C、INFJ-O-C、INTJ-A-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

INFJ-A-Cの「A」と「C」は何を表していますか？

Aは自分への確信の軸で、確信＝自分の判断を疑わず、迷いが短いという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じINFJでも、この2文字が変わると現れ方が変わります。

INFJ-A-Cは「INFJ-AC」や「INFJ AC」と同じですか？

同じものです。INFJ-A-C・INFJ-AC・INFJ AC・INFJ A C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。

INFJ-A-C は診断結果の1つです。自分がどのタイプかは、受けてみると分かります。
