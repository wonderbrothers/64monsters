ENFJ-O-C とは

ENFJ-O-C（ENFJ-OC／ENFJ OC とも書かれます）は、64タイプ性格診断のうちの1つです。ENFJの4文字に、自分への確信を表すO（揺らぎ）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「静かに支える伴走モンスター」と呼んでいます。

相手のなかにある力を見つけ、引き出すことに喜びを感じます。場の空気をつくるのがうまく、自然と中心的な役割を担います。他者のために動きすぎて、自分の状態が後回しになりがちです。

人の成長を願いながら、それを表に出さないタイプ。自分の関わり方を何度も見直し、相手との距離も慎重に測るので、支えていることに本人が気づかないことすらあります。一対一の場面でだけ、その深さが現れます。

よくある質問

ENFJ-O-Cとはどんなタイプですか？

ENFJ-O-Cは「静かに支える伴走モンスター」です。人の可能性に火を灯し、隣で走る人というENFJの性質に、自分への確信がO（揺らぎ）、人への構えがC（慎重）の組み合わせが重なります。人の成長を願いながら、それを表に出さないタイプ。自分の関わり方を何度も見直し、相手との距離も慎重に測るので、支えていることに本人が気づかないことすらあります。一対一の場面でだけ、その深さが現れます。

ENFJ-O-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはENFJ-A-C、ESFJ-A-C、INFJ-A-C、仕事のパートナーとしてはISTJ-A-C、ESTJ-A-C、ISFJ-A-C、友人としてはENTJ-A-C、ENFJ-A-C、ENTJ-O-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

ENFJ-O-Cの「O」と「C」は何を表していますか？

Oは自分への確信の軸で、揺らぎ＝決めたあとも考え直し、揺れながら精度を上げるという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じENFJでも、この2文字が変わると現れ方が変わります。

ENFJ-O-Cは「ENFJ-OC」や「ENFJ OC」と同じですか？

同じものです。ENFJ-O-C・ENFJ-OC・ENFJ OC・ENFJ O C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。
