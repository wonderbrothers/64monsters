ENTP-A-C とは

ENTP-A-C（ENTP-AC／ENTP AC）は、ベースコード ENTP に、独自軸のA（確信）とC（慎重）が重なるタイプです。64モンスターズでは「斬り込む突破モンスター」と呼んでいます。

「そもそも、こうしたらどうか」と切り込むのが得意です。着想が次々に湧き、議論のなかで思考が加速します。飽きが早く、始めることと続けることの落差が課題になりやすいタイプです。

前提そのものを淡々と壊しにいくタイプ。感情の温度を上げずに矛盾を突くので指摘が正確で、しかも自分の判断に迷いがありません。ただ、相手が信用できるかを見きわめてから距離を詰めるため、正しさが伝わる前に「手厳しい人」という印象が先に立ってしまうことがあります。

コードの読み方は64タイプ性格診断とはに、設問と採点の作り方はこの診断についてにまとめています。

ENTP-O-C との違い

どちらも相手を見きわめてから口を開きます。ENTP-A-C は矛盾に気づいた時点で迷わず指摘し、ENTP-O-C はその指摘が本当に正しいかを自分のなかで確かめてから動きます。A-C は言うべきことを遅らせず、O-C は外れのない一手を選びます。

ENTP-A-H との違い

どちらも自分の判断を疑わず、前提を壊すことをためらいません。ENTP-A-C は相手を選び、温度を上げずに論点だけを突き、ENTP-A-H は誰にでも思いつきを投げて場ごと巻き込みます。A-C の指摘は正確で、A-H の提案には勢いがあります。

ENTP-A-C の強みと、気をつけたいところ

強み

場の空気や力関係に流されず、論点だけを見て切り込める。誰も言わなかったことを、必要な場面で必要なだけ言えます。

  • 感情的になった議論のなかでも、自分の判断を見失わずにいられる
  • 信用した相手には、表面をなぞらない率直な助言を渡せる
  • 普段は黙っているぶん、発言の一つひとつが重く受け取られる

落とし穴

指摘の速さと距離の遠さが重なると、相手には拒絶に見える。結論の前に「ここは同意している」と一言置くだけで、通り方がまるで変わります。

  • 指摘を一度に並べてしまい、相手の受け取れる量を超える
  • 信用していない相手の提案を、聞く前から低く見積もりやすい
  • 怒っていないのに、淡々とした口調が冷たく受け取られる

ENTP-A-C がつまずきやすい場面

  1. 後輩が出した企画書の矛盾を三つ見つけて順番に指摘したら、相手が最後まで何も言わなくなった。

    指摘はいちばん大きいもの一つに絞り、残りは聞かれたら答える。全部が正しくても、一度に受け取れる数には限りがあります。

  2. 新しいチームの打ち合わせで、相手をよく知らないうちは黙っていて、話しはじめた途端に核心を突いて場が固まる。

    最初の打ち合わせで、質問を一つだけしておく。黙っていた人がいきなり切り込むより、ずっと受け止められやすくなります。

  3. 家族から買い物の相談を受け、値段と性能の比較だけで答えて「そういう話じゃない」と言われる。

    答える前に「決めたいのか、聞いてほしいのか」を一言たずねる。求められているのが判断ではないときもあります。
