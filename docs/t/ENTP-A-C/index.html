ENTP-A-C とは

ENTP-A-C（ENTP-AC／ENTP AC とも書かれます）は、64タイプ性格診断のうちの1つです。ENTPの4文字に、自分への確信を表すA（確信）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「斬り込む突破モンスター」と呼んでいます。

「そもそも、こうしたらどうか」と切り込むのが得意です。着想が次々に湧き、議論のなかで思考が加速します。飽きが早く、始めることと続けることの落差が課題になりやすいタイプです。

前提そのものを淡々と壊しにいくタイプ。感情の温度を上げずに矛盾を突くので指摘が正確で、しかも自分の判断に迷いがありません。ただ、相手が信用できるかを見きわめてから距離を詰めるため、正しさが伝わる前に「手厳しい人」という印象が先に立ってしまうことがあります。

よくある質問

ENTP-A-Cとはどんなタイプですか？

ENTP-A-Cは「斬り込む突破モンスター」です。前提をひっくり返して、可能性を試す人というENTPの性質に、自分への確信がA（確信）、人への構えがC（慎重）の組み合わせが重なります。前提そのものを淡々と壊しにいくタイプ。感情の温度を上げずに矛盾を突くので指摘が正確で、しかも自分の判断に迷いがありません。ただ、相手が信用できるかを見きわめてから距離を詰めるため、正しさが伝わる前に「手厳しい人」という印象が先に立ってしまうことがあります。

ENTP-A-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはENTP-O-C、ESTP-O-C、INTP-O-C、仕事のパートナーとしてはISFP-O-C、ESFP-O-C、ISTP-O-C、友人としてはENFP-O-C、ENTP-O-C、ENFP-A-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

ENTP-A-Cの「A」と「C」は何を表していますか？

Aは自分への確信の軸で、確信＝自分の判断を疑わず、迷いが短いという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じENTPでも、この2文字が変わると現れ方が変わります。

ENTP-A-Cは「ENTP-AC」や「ENTP AC」と同じですか？

同じものです。ENTP-A-C・ENTP-AC・ENTP AC・ENTP A C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。
