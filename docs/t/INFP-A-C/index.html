INFP-A-C とは

INFP-A-C（INFP-AC／INFP AC）は、ベースコード INFP に、独自軸のA（確信）とC（慎重）が重なるタイプです。64モンスターズでは「静かに譲らない空想モンスター」と呼んでいます。

何が正しいかより「何を大切にしたいか」で動きます。内面世界が豊かで、言葉やイメージにこだわります。譲れない一線に触れられたときだけ、驚くほど頑固になります。

何も主張しないように見えて、一線だけは絶対に動かないタイプ。価値観に迷いがなく、しかも人には簡単に開かないので、譲れない理由が外からは分かりません。ある日突然、静かに、しかし完全に引かない態度が現れます。

INFP-A-Cとはどんなタイプですか？

INFP-A-Cは「静かに譲らない空想モンスター」です。何も主張しないように見えて、一線だけは絶対に動かないタイプ。価値観に迷いがなく、しかも人には簡単に開かないので、譲れない理由が外からは分かりません。ある日突然、静かに、しかし完全に引かない態度が現れます。
