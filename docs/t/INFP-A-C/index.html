INFP-A-C とは

INFP-A-C（INFP-AC／INFP AC とも書かれます）は、64タイプ性格診断のうちの1つです。INFPの4文字に、自分への確信を表すA（確信）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「静かに譲らない空想モンスター」と呼んでいます。

何が正しいかより「何を大切にしたいか」で動きます。内面世界が豊かで、言葉やイメージにこだわります。譲れない一線に触れられたときだけ、驚くほど頑固になります。

何も主張しないように見えて、一線だけは絶対に動かないタイプ。価値観に迷いがなく、しかも人には簡単に開かないので、譲れない理由が外からは分かりません。ある日突然、静かに、しかし完全に引かない態度が現れます。

よくある質問

INFP-A-Cとはどんなタイプですか？

INFP-A-Cは「静かに譲らない空想モンスター」です。自分の価値観に、正直であろうとする人というINFPの性質に、自分への確信がA（確信）、人への構えがC（慎重）の組み合わせが重なります。何も主張しないように見えて、一線だけは絶対に動かないタイプ。価値観に迷いがなく、しかも人には簡単に開かないので、譲れない理由が外からは分かりません。ある日突然、静かに、しかし完全に引かない態度が現れます。

INFP-A-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはINFP-O-C、ISFP-O-C、ENFP-O-C、仕事のパートナーとしてはESTP-O-C、ISTP-O-C、ESFP-O-C、友人としてはINTP-O-C、INFP-O-C、INTP-A-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

INFP-A-Cの「A」と「C」は何を表していますか？

Aは自分への確信の軸で、確信＝自分の判断を疑わず、迷いが短いという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じINFPでも、この2文字が変わると現れ方が変わります。

INFP-A-Cは「INFP-AC」や「INFP AC」と同じですか？

同じものです。INFP-A-C・INFP-AC・INFP AC・INFP A C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。

INFP-A-C は診断結果の1つです。自分がどのタイプかは、受けてみると分かります。
