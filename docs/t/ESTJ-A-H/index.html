ESTJ-A-Hとはどんなタイプですか？

ESTJ-A-Hは「面倒見のいい仕切りモンスター」です。64モンスターズが90問の回答から分類する64タイプのひとつで、ベースコードESTJに、独自軸のA（確信）とH（信頼）が重なります。やるべきことを決めて配り、そのうえで一人ひとりの面倒まで見るタイプ。判断に迷いがなく、任せた相手も信じているので、現場が速く回ります。ただ、信じて任せたぶんだけ期待も乗るので、応えられなかった側には重さとして届きます。

ESTJ-A-Hの「A」は何を表していますか？

Aは、64モンスターズが独自に加えている「自分への確信」の軸です。A＝確信で、自分の判断を疑わず、迷いが短いという意味です。もう一方の極はO（揺らぎ）で、この1文字が変わると同じベースコードでも現れ方が変わります。

ESTJ-A-Hの「H」は何を表していますか？

Hは、64モンスターズが独自に加えている「人への構え」の軸です。H＝信頼で、まず信じて、自分から開いていくという意味です。ベースコードとは別に判定するので、どのベースコードの人にもHとCの両方がいます。

ESTJ-A-Hと同じESTJベースコードのタイプには何がありますか？

ESTJ-A-H、ESTJ-A-C、ESTJ-O-H、ESTJ-O-Cの4つです。ベースコードは同じで、独自軸の A / O（自分への確信）と H / C（人への構え）の組み合わせだけが違います。ESTJ-A-HはA（確信）とH（信頼）、ESTJ-A-CはA（確信）とC（慎重）です。
