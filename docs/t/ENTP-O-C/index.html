ENTP-O-Cとはどんなタイプですか？

ENTP-O-Cは「静かに企てる突破モンスター」です。64モンスターズが90問の回答から分類する64タイプのひとつで、ベースコードENTPに、独自軸のO（揺らぎ）とC（慎重）が重なります。外からは派手に見えないENTP。頭のなかでは反証と別案を回し続けていますが、それを人に見せるのは相手を見きわめてからです。考え抜いたぶん打つ手の精度は高く、機が熟したときに一手で動かします。ただし、その一手が出るまでに機会そのものが消えていることもあります。

ENTP-O-Cの「O」は何を表していますか？

Oは、64モンスターズが独自に加えている「自分への確信」の軸です。O＝揺らぎで、決めたあとも考え直し、揺れながら精度を上げるという意味です。もう一方の極はA（確信）で、この1文字が変わると同じベースコードでも現れ方が変わります。

ENTP-O-Cの「C」は何を表していますか？

Cは、64モンスターズが独自に加えている「人への構え」の軸です。C＝慎重で、見きわめてから、距離を縮めるという意味です。ベースコードとは別に判定するので、どのベースコードの人にもCとHの両方がいます。

ENTP-O-Cと同じENTPベースコードのタイプには何がありますか？

ENTP-A-H、ENTP-A-C、ENTP-O-H、ENTP-O-Cの4つです。ベースコードは同じで、独自軸の A / O（自分への確信）と H / C（人への構え）の組み合わせだけが違います。ENTP-O-CはO（揺らぎ）とC（慎重）、ENTP-A-HはA（確信）とH（信頼）です。

ENTP-O-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはENTP-A-C、ESTP-A-C、INTP-A-C、仕事のパートナーとしてはISFP-A-C、ESFP-A-C、ISTP-A-C、友人としてはENFP-A-C、ENTP-A-C、ENFP-O-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。設計した重みによる目安で、測定値ではありません。
