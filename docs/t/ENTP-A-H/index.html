ENTP-A-H とは

ENTP-A-H（ENTP-AH／ENTP AH）は、ベースコード ENTP に、独自軸のA（確信）とH（信頼）が重なるタイプです。64モンスターズでは「場を焚きつける突破モンスター」と呼んでいます。

「そもそも、こうしたらどうか」と切り込むのが得意です。着想が次々に湧き、議論のなかで思考が加速します。飽きが早く、始めることと続けることの落差が課題になりやすいタイプです。

思いついたことをその場で口にし、人を巻き込みながら形にしていくタイプ。自分の見立てを疑わないので動き出しが速く、初対面の相手にも遠慮なく話を持ちかけます。止まっていた空気を一度で変えてしまう強さがある反面、巻き込んだ人が同じ速さでついてこられているかの確認は、後回しになりがちです。

コードの読み方は64タイプ性格診断とはに、設問と採点の作り方はこの診断についてにまとめています。

ENTP-O-H との違い

どちらも人を巻き込みながら考えます。ENTP-A-H は自分の見立てを言い切って先頭を走り、ENTP-O-H は人の案を取り込みながら何度も戻ってきます。A-H は止まった場を一度で動かし、O-H は時間をかけて中身を育てます。

ENTP-A-C との違い

どちらも判断に迷いがなく、前提を壊しにいきます。ENTP-A-H は初対面の相手にも思いつきを投げて巻き込み、ENTP-A-C は相手を見きわめてから、矛盾だけを正確に突きます。A-H は場を熱くし、A-C は場の温度を上げずに論点を絞ります。

ENTP-A-H の強みと、気をつけたいところ

強み

「誰に持っていけば動くか」の判断が速く、そこにためらいがない。人の力を借りることに抵抗がないぶん、ひとりでは届かない規模まで話を運べます。

  • 企画の話を聞いた相手が、つい手伝いたくなる勢いがある
  • 自分の案が退けられても引きずらず、すぐ次の案を出せる
  • 初対面の相手とも、その場で一緒に考える関係をつくれる

落とし穴

任せた相手を信じきってしまい、あとで見たら誰も動いていなかった、が起きやすい。渡した翌日に一度だけ様子を見にいくだけで、かなり防げます。

  • 相手の話を聞き終わる前に、自分の案で上書きしてしまう
  • 勢いで決めたことを、関係者に共有しないまま進めてしまう
  • 近い相手ほど遠慮なく突いて、否定されたと受け取られる

ENTP の4タイプに共通する強みと注意点

ENTP-A-H がつまずきやすい場面

  1. 定例会議で思いついた別案を話しはじめ、気づけば予定していた議題が一つも終わっていない。

    別案は会議の最後の10分に回すと決めておく。メモしておけば、思いつきは逃げません。

  2. 友人の転職の相談に、聞き終わる前から「それなら起業すればいい」と勢いよく返して、相手が黙り込む。

    提案する前に「いちばん困っていることは何？」と一つだけ聞く。相手の前提を知ってからひっくり返すほうが、話は前に進みます。

  3. 立ち上げた企画のチャットに次々と案を投げ、気づけばメンバーの誰も返信しなくなっている。

    案は一回に一つ、誰に返事がほしいかを添えて投げる。受け取る側が、どこから手をつければいいか分かります。

すでに近い相手とのあいだで

近い相手ほど遠慮なく突きます。議論のつもりでも、相手には否定として届くことがあります。こちらは関心があるから突いているのですが、それは説明しないと伝わりません。
