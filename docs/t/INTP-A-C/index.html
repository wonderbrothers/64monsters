INTP-A-C とは

INTP-A-C（INTP-AC／INTP AC）は、ベースコード INTP に、独自軸のA（確信）とC（慎重）が重なるタイプです。64モンスターズでは「割り切る分解モンスター」と呼んでいます。

「なぜそうなるのか」が腑に落ちないと前に進めません。矛盾や穴に敏感で、議論では前提そのものを問い直します。関心のある問いには驚くほどの集中を見せる一方、興味の外側には淡白です。

分かったところで手を止め、分からないところは切り捨てられるタイプ。判断に迷いがなく、しかも相手を見きわめてからしか口を開かないので、発言の数は少ないのに外れません。ただ、結論だけが短く置かれるため、周囲にはそっけなく映ります。

コードの読み方は64タイプ性格診断とはに、設問と採点の作り方はこの診断についてにまとめています。

INTP-A-Cとはどんなタイプですか？

INTP-A-Cは「割り切る分解モンスター」です。分かったところで手を止め、分からないところは切り捨てられるタイプ。判断に迷いがなく、しかも相手を見きわめてからしか口を開かないので、発言の数は少ないのに外れません。ただ、結論だけが短く置かれるため、周囲にはそっけなく映ります。

INTP-A-Cはどんな仕事で力を発揮しやすいですか？

問いの立て方から任され、思考の時間が確保できる環境で力を発揮しやすく、分析、設計、技術検証、複雑な問題の解きほぐしといった役割を担いやすいタイプです。INTP-A-Cの場合は、難所の判断が速い。結論だけでなく根拠を渡すと信頼が積み上がる。

INTP-A-Cの恋愛傾向は？

INTP-A-Cは「INTP-AC」や「INTP AC」と同じですか？

同じものです。INTP-A-C・INTP-AC・INTP AC は、いずれも同じ組み合わせを指します。
