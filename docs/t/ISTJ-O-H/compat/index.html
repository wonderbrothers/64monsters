ISTJ-O-H の相性

ISTJ-O-H（念を入れる几帳面モンスター）は、エネルギーの向きは内向、情報の受け取り方は感覚、判断の基準は思考、外界への構えは計画、自分への確信は揺らぎ、人への構えは信頼。この6つが相手とどう噛み合うかで、恋人・仕事のパートナー・友人それぞれの順位が決まります。6軸の重みづけから計算した目安であって、測定値ではありません。

ISTJ-O-H が関係のなかでやっていること

一度で済むはずの確認を、二度三度と重ねます。自分の判断を疑う構えなので念押しが止まらず、人への構えが開いているので聞く相手には困りません。関係のなかでも同じで、相手の気持ちや予定を何度も確認します。疑っているのは相手ではなく自分の受け取り方なのですが、その区別は外に伝わりません。聞かれた側は、信用されていないと感じます。確認するほど安心する側と、確認されるほど不安になる側が、同じ関係のなかで向かい合っている。善意しかないのに、増えるのは相手の不安のほうです。

かみ合っているときの形

何度聞いても、同じ答えが返ってくるときです。答えが揺れないと、確認の回数が自然に減ります。逆に、答えが毎回少し違う相手だと、この人の確認は永遠に終わりません。もうひとつは、確認の終点を決めてくれる相手。ここまで確かめたら終わり、と外から線を引かれると、そこで安心できます。自分で引いた線は、必ず引き直してしまいます。外から引いてもらうことだけが、この人を休ませます。答えの揺れない相手ほど、結果として長く一緒にいられます。

崩れるときの入り口

つまずくのは、三度目の確認です。一度目は丁寧、二度目は慎重、三度目から相手には別の意味になります。もうひとつは、確認の対象が相手の気持ちに向いたときです。予定や手順なら何度聞いても実務ですが、気持ちを何度も聞かれると、相手は答えのほうを疑われていると受け取ります。答え直すたびに、最初の答えの重みが相手のなかで減っていきます。確認の回数が、そのまま不信の量として翻訳されていきます。

よくある質問

ISTJ-O-Hと最も相性がいいのはどのタイプですか？

用途によって変わります。恋人として噛み合うのはISTJ-A-H、INTJ-A-H、ESTJ-A-H、仕事のパートナーとしてはENFJ-A-H、INFJ-A-H、ENTJ-A-H、友人としてはISFJ-A-H、ISTJ-A-H、ISFJ-O-Hが上位です。ひとつの答えにならないのは、同じ相手でも用途ごとに効く軸が違うからです。

相性のスコアは何を根拠にしていますか？

測定値ではありません。6つの軸それぞれについて「一致が効くか、違いが効くか」を用途別に重みづけし、かみ合っている軸の重みが全体の何割かを出しています。ISTJ-O-HはI＝内向・S＝感覚・T＝思考・J＝計画・O＝揺らぎ・H＝信頼なので、この6つが相手と揃うか外れるかで順位が決まります。設計した重みなので、数値だけでなく必ずどの軸が効いたかと一緒に見てください。

ISTJ-O-H同士の相性はどうですか？

ISTJ-O-H同士も相手として数えていて、恋人4位・仕事45位・友人5位です。6つの軸がすべて同じになるので、一致が効く用途では上位に来て、違いが効く用途では下がります。同じタイプだから相性がいい、とも悪いとも決めていません。

ISTJ-O-Hと相性の悪いタイプはいますか？

順位の下のほうに来るタイプはあります。ISTJ-O-Hの場合、恋人ではENFP-O-C、ESFP-O-C、INFP-O-C、仕事ではISTP-O-C、ESTP-O-C、ISFP-O-C、友人ではENTP-O-C、ENFP-O-C、ENTP-A-Cが下位3タイプです。ただし悪いという扱いはしていません。噛み合いにくい相手は、価値観の置き所が違うぶん、自分に足りない視点を最も速く手渡してくれる相手でもあります。

ISTJ-O-HとISTJ-A-Hはなぜ恋人として1位なのですか？

ISTJ-O-HとISTJ-A-H（頼れる几帳面モンスター）は、恋人としてのスコアが100で64タイプ中1位です。かみ合っているのは外界への構え、判断の基準、人への構え、エネルギーの向き、情報の受け取り方、自分への確信で、予定や家事の進め方が揃い、暮らしの摩擦が少ない。6軸すべてがかみ合っていて、恋人として見たときにずれる軸がありません。

相手のコードが分かれば、2人ぶんの内訳をその場で見られます。
