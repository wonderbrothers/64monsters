INTJ-O-C とは

INTJ-O-C（INTJ-OC／INTJ OC）は、ベースコード INTJ に、独自軸のO（揺らぎ）とC（慎重）が重なるタイプです。64モンスターズでは「沈潜する設計モンスター」と呼んでいます。

頭のなかに「こうあるべき最終形」があり、そこから逆算して現在を設計します。目先の空気より構造の正しさを優先するため、判断は速く、そして孤独になりがちです。理解されるまで説明を尽くすより、結果で示そうとする傾向があります。

問いを抱えたまま、ひとりで深く潜っていくタイプ。考え直しが続くうえ、途中経過を見せる相手も選ぶので、外からは長い沈黙に見えます。浮かんできたときには誰も辿り着けない深さまで行っていますが、その間、周囲は何も知りません。

コードの読み方は64タイプ性格診断とはに、設問と採点の作り方はこの診断についてにまとめています。

INTJ-A-C との違い

どちらも考えを外に出すまでが長いタイプです。INTJ-O-C はそのあいだずっと前提を問い直していて、INTJ-A-C は早くに出た結論を実行の時機まで温めています。O-C は検討の深さで、A-C は判断の揺るぎなさで頼られます。

INTJ-O-H との違い

どちらも考え直しを続けます。INTJ-O-C は見せる相手を選んでひとりで深く潜り、INTJ-O-H は途中を人に見せて意見を取り込みます。O-C の検討は深く、O-H の検討は広い。外から進み具合が見えにくいのは O-C のほうです。

INTJ-O-C の強みと、気をつけたいところ

強み

誰も手をつけない難問に、時間をかけて向き合える。長期の研究や、答えのない設計に強さが出ます。

  • 他人の結論をうのみにせず、元の資料までさかのぼって確かめられる
  • 途中で人に流されないので、検討の筋道が最後まで一本につながっている
  • 自分の誤りに自分で気づけるので、出したものに後から穴が見つかりにくい

落とし穴

沈黙が長いほど「止まっている」と誤解される。週に一度、進んだかどうかだけでも外に出す約束をしておくと、潜る時間そのものを守れます。

  • 確かめ終わるまで出さないので、早く出せば役立った情報が遅れて届く
  • 意見を求められても前提の確認から始め、相手が欲しい答えに届かない
  • 人に聞けば一日で済む調べものにも、ひとりで一週間かけてしまう

INTJ の4タイプに共通する強みと注意点

INTJ-O-C がつまずきやすい場面

  1. 上司に進捗を聞かれて「まだです」と答え続け、別の担当者に仕事を振り直されそうになる。

    完成度ではなく、確かめ終えた項目の数で答える。「十のうち六まで見た」と言えるだけで、止まっていないことが伝わります。

  2. 勉強会で質問され、答えかけたものの前提に穴がある気がして「確認します」と引き取り、そのまま返事をしないでいる。

    引き取った問いには、答えが出ていなくても三日以内に一度返す。「ここまで分かって、ここが未確認」と書くだけで、問いが相手との共同作業になります。

  3. 週末に一人で始めた調べものに没頭し、家族との約束の時間を過ぎていることに気づかない。

    潜る前に、終わりの時刻をアラームで決めておく。時間を外に預けておくと、安心して深く潜れます。

恋愛での INTJ-O-C

INTJ-O-Cは、気持ちが動いてから形になるまでが、いちばん長いタイプです。ひとりで確かめ、ひとりで疑い、外には何も出ないまま時間が過ぎます。

かみ合う相手

待てる相手、あるいは自分から近づいてくれる相手。距離を詰める役を相手が担ってくれると、そこから関係が始まります。

気をつけたいところ

沈黙が長いと、相手は脈がないと判断して離れていく。「考えている最中だ」と伝えるだけでいい。内容ではなく状態を渡すのが効きます。

INTJ-O-C の人間関係

INTJ-O-Cは、人との関係でも、まず自分のなかで何度も確かめます。確かめ終わるまで出さず、出す相手も選ぶので、関わりの立ち上がりがいちばん遅いタイプです。

すでに近い相手とのあいだで

長く一緒にいる相手にも、迷っている最中のことは話しません。整理がついてから渡すので、相手は結果だけを知らされます。悩んでいたことに誰も気づかないまま終わります。

まだ近くない相手とのあいだで

相手を測る時間と、自分の見立てを確かめる時間が重なるので、二重に時間がかかります。そのあいだ関係は進みません。こちらに拒否の意思はまったくありません。
