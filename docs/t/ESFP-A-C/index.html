ESFP-A-C とは

ESFP-A-C（ESFP-AC／ESFP AC）は、ベースコード ESFP に、独自軸のA（確信）とC（慎重）が重なるタイプです。64モンスターズでは「粋なお祭りモンスター」と呼んでいます。

場を明るくし、人を楽しませることに長けています。五感が鋭く、体験を通して学びます。先の計画より目の前の充実を選ぶため、続ける仕組みづくりが課題になります。

場を楽しませながら、自分の間合いは崩さないタイプ。判断に迷いがなく、相手を見きわめてから懐に入れるので、賑やかさのなかに芯があります。近づきすぎない距離感が魅力になりますが、本当のところを見せる相手はごく少数です。
