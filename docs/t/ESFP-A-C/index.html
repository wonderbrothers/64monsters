ESFP-A-C とは

ESFP-A-C（ESFP-AC／ESFP AC とも書かれます）は、64タイプ性格診断のうちの1つです。ESFPの4文字に、自分への確信を表すA（確信）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「粋なお祭りモンスター」と呼んでいます。

場を明るくし、人を楽しませることに長けています。五感が鋭く、体験を通して学びます。先の計画より目の前の充実を選ぶため、続ける仕組みづくりが課題になります。

場を楽しませながら、自分の間合いは崩さないタイプ。判断に迷いがなく、相手を見きわめてから懐に入れるので、賑やかさのなかに芯があります。近づきすぎない距離感が魅力になりますが、本当のところを見せる相手はごく少数です。

よくある質問

ESFP-A-Cとはどんなタイプですか？

ESFP-A-Cは「粋なお祭りモンスター」です。いまこの瞬間を、豊かにしてしまう人というESFPの性質に、自分への確信がA（確信）、人への構えがC（慎重）の組み合わせが重なります。場を楽しませながら、自分の間合いは崩さないタイプ。判断に迷いがなく、相手を見きわめてから懐に入れるので、賑やかさのなかに芯があります。近づきすぎない距離感が魅力になりますが、本当のところを見せる相手はごく少数です。

ESFP-A-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはESFP-O-C、ENFP-O-C、ISFP-O-C、仕事のパートナーとしてはINTP-O-C、ENTP-O-C、INFP-O-C、友人としてはESTP-O-C、ESFP-O-C、ESTP-A-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

ESFP-A-Cの「A」と「C」は何を表していますか？

Aは自分への確信の軸で、確信＝自分の判断を疑わず、迷いが短いという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じESFPでも、この2文字が変わると現れ方が変わります。

ESFP-A-Cは「ESFP-AC」や「ESFP AC」と同じですか？

同じものです。ESFP-A-C・ESFP-AC・ESFP AC・ESFP A C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。

ESFP-A-C は診断結果の1つです。自分がどのタイプかは、受けてみると分かります。
