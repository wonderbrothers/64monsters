INTP-O-C とは

INTP-O-C（INTP-OC／INTP OC とも書かれます）は、64タイプ性格診断のうちの1つです。INTPの4文字に、自分への確信を表すO（揺らぎ）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「閉じこもる分解モンスター」と呼んでいます。

この INTP という4文字は、64モンスターズ独自の設問と採点による結果を表すものです。ほかの性格検査による判定を示すものではありません。コードの読み方

「なぜそうなるのか」が腑に落ちないと前に進めません。矛盾や穴に敏感で、議論では前提そのものを問い直します。関心のある問いには驚くほどの集中を見せる一方、興味の外側には淡白です。

納得できるまで、ひとりで検証を続けるタイプ。考え直しが止まらないうえ、途中の未完成な考えを人に見せたがらないので、外との接点が細くなります。出てきたものの質は高いのですが、そこに至るまでの時間は誰にも見えていません。

よくある質問

INTP-O-Cとはどんなタイプですか？

INTP-O-Cは「閉じこもる分解モンスター」です。仕組みを分解して、腑に落ちるまで考える人というINTPの性質に、自分への確信がO（揺らぎ）、人への構えがC（慎重）の組み合わせが重なります。納得できるまで、ひとりで検証を続けるタイプ。考え直しが止まらないうえ、途中の未完成な考えを人に見せたがらないので、外との接点が細くなります。出てきたものの質は高いのですが、そこに至るまでの時間は誰にも見えていません。

INTP-O-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはINTP-A-C、ISTP-A-C、ENTP-A-C、仕事のパートナーとしてはESFP-A-C、ISFP-A-C、ESTP-A-C、友人としてはINFP-A-C、INTP-A-C、INFP-O-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

INTP-O-Cの「O」と「C」は何を表していますか？

Oは自分への確信の軸で、揺らぎ＝決めたあとも考え直し、揺れながら精度を上げるという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じINTPでも、この2文字が変わると現れ方が変わります。

INTP-O-Cは「INTP-OC」や「INTP OC」と同じですか？

同じものです。INTP-O-C・INTP-OC・INTP OC・INTP O C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。

INTP-O-C は診断結果の1つです。自分がどのタイプかは、受けてみると分かります。
