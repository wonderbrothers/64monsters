ESTJ-O-C とは

ESTJ-O-C（ESTJ-OC／ESTJ OC とも書かれます）は、64タイプ性格診断のうちの1つです。ESTJの4文字に、自分への確信を表すO（揺らぎ）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「慎重な仕切りモンスター」と呼んでいます。

やるべきことを決め、人を配置し、期日までに終わらせます。責任の所在をはっきりさせることを重視し、曖昧な合意を嫌います。頼れる反面、正論が強く出やすいタイプです。

決めるまでに時間をかけ、その検討を人に見せないタイプ。判断を何度も疑い、相手も見きわめるので、動き出しは遅くなります。ただ、動き始めてからの手戻りはほとんどなく、決めた運用は長く安定して回り続けます。

よくある質問

ESTJ-O-Cとはどんなタイプですか？

ESTJ-O-Cは「慎重な仕切りモンスター」です。現場を整え、確実に回していく人というESTJの性質に、自分への確信がO（揺らぎ）、人への構えがC（慎重）の組み合わせが重なります。決めるまでに時間をかけ、その検討を人に見せないタイプ。判断を何度も疑い、相手も見きわめるので、動き出しは遅くなります。ただ、動き始めてからの手戻りはほとんどなく、決めた運用は長く安定して回り続けます。

ESTJ-O-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはESTJ-A-C、ENTJ-A-C、ISTJ-A-C、仕事のパートナーとしてはINFJ-A-C、ENFJ-A-C、INTJ-A-C、友人としてはESFJ-A-C、ESTJ-A-C、ESFJ-O-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

ESTJ-O-Cの「O」と「C」は何を表していますか？

Oは自分への確信の軸で、揺らぎ＝決めたあとも考え直し、揺れながら精度を上げるという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じESTJでも、この2文字が変わると現れ方が変わります。

ESTJ-O-Cは「ESTJ-OC」や「ESTJ OC」と同じですか？

同じものです。ESTJ-O-C・ESTJ-OC・ESTJ OC・ESTJ O C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。
