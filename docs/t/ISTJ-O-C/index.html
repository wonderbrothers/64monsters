ISTJ-O-C とは

ISTJ-O-C（ISTJ-OC／ISTJ OC とも書かれます）は、64タイプ性格診断のうちの1つです。ISTJの4文字に、自分への確信を表すO（揺らぎ）と、人への構えを表すC（慎重）が重なります。64モンスターズでは「石橋を叩く几帳面モンスター」と呼んでいます。

任されたことを、決めた通りに、期日までに仕上げます。派手さより信頼で評価される働き方を選び、事実と前例を土台に判断します。曖昧なまま進む状況に、強いストレスを感じます。

確かめて、そのうえでもう一度確かめてから渡るタイプ。自分の判断を疑い、人にも簡単には相談しないので、慎重さが二重にかかります。間違いはほとんど起きませんが、渡り終える頃には、向こう岸の状況が変わっていることがあります。

よくある質問

ISTJ-O-Cとはどんなタイプですか？

ISTJ-O-Cは「石橋を叩く几帳面モンスター」です。約束を、確実に果たしていく人というISTJの性質に、自分への確信がO（揺らぎ）、人への構えがC（慎重）の組み合わせが重なります。確かめて、そのうえでもう一度確かめてから渡るタイプ。自分の判断を疑い、人にも簡単には相談しないので、慎重さが二重にかかります。間違いはほとんど起きませんが、渡り終える頃には、向こう岸の状況が変わっていることがあります。

ISTJ-O-Cと相性がいいタイプは？

用途によって変わります。恋人として噛み合うのはISTJ-A-C、INTJ-A-C、ESTJ-A-C、仕事のパートナーとしてはENFJ-A-C、INFJ-A-C、ENTJ-A-C、友人としてはISFJ-A-C、ISTJ-A-C、ISFJ-O-Cが上位です。6つの軸それぞれに「一致が効くか、違いが効くか」を用途別に重みづけして、64タイプを順位づけしています。同じタイプ同士も相手として数えています。

ISTJ-O-Cの「O」と「C」は何を表していますか？

Oは自分への確信の軸で、揺らぎ＝決めたあとも考え直し、揺れながら精度を上げるという意味です。Cは人への構えの軸で、慎重＝見きわめてから、距離を縮めるという意味です。同じISTJでも、この2文字が変わると現れ方が変わります。

ISTJ-O-Cは「ISTJ-OC」や「ISTJ OC」と同じですか？

同じものです。ISTJ-O-C・ISTJ-OC・ISTJ OC・ISTJ O C は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。
