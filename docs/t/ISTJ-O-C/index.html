ISTJ-O-Cとはどんなタイプですか？

ISTJ-O-Cは「石橋を叩く几帳面モンスター」です。64モンスターズが90問の回答から分類する64タイプのひとつで、ベースコードISTJに、独自軸のO（揺らぎ）とC（慎重）が重なります。確かめて、そのうえでもう一度確かめてから渡るタイプ。自分の判断を疑い、人にも簡単には相談しないので、慎重さが二重にかかります。間違いはほとんど起きませんが、渡り終える頃には、向こう岸の状況が変わっていることがあります。

ISTJ-O-Cの「O」は何を表していますか？

Oは、64モンスターズが独自に加えている「自分への確信」の軸です。O＝揺らぎで、決めたあとも考え直し、揺れながら精度を上げるという意味です。もう一方の極はA（確信）で、この1文字が変わると同じベースコードでも現れ方が変わります。

ISTJ-O-Cの「C」は何を表していますか？

Cは、64モンスターズが独自に加えている「人への構え」の軸です。C＝慎重で、見きわめてから、距離を縮めるという意味です。ベースコードとは別に判定するので、どのベースコードの人にもCとHの両方がいます。

ISTJ-O-Cと同じISTJベースコードのタイプには何がありますか？
