64タイプ性格診断とは

MBTIとして広く知られている4文字の16タイプに、自分への確信（A / O）と人への構え（H / C）の2つの軸を足したものです。16 × 2 × 2 で64通りになります。INTJ-O-H のように書きます。

コードの読み方

INTJ基本の4文字エネルギーの向き・情報の受け取り方・判断の基準・外界への構え。16タイプと同じ4軸です。
O自分への確信A（確信）か O（揺らぎ）。決めたあとに戻ってくるかどうかの軸です。くわしく
H人への構えH（信頼）か C（慎重）。人にまず開くか、見きわめてから近づくかの軸です。くわしく

6つの軸

64モンスターズは、次の6つの軸で判定しています。上の4つが16タイプと共通、下の2つが64タイプで足される軸です。

軸一方の極もう一方の極
エネルギーの向きE / I E・外向人と関わることで充電される I・内向ひとりの時間で充電される
情報の受け取り方S / N S・感覚事実と手ざわりから理解する N・直観意味とつながりから理解する
判断の基準T / F T・思考筋道と一貫性で決める F・感情人と価値への影響で決める
外界への構えP / J P・探索決めきらずに幅を残す J・計画決めて片づけていく
自分への確信A / O A・確信自分の判断を疑わず、迷いが短い O・揺らぎ決めたあとも考え直し、揺れながら精度を上げる
人への構えC / H C・慎重見きわめてから、距離を縮める H・信頼まず信じて、自分から開いていく

それぞれ満点30に対する寄りで測り、差が3以内のときは「立っていない」として扱います。

表記のゆれについて

同じ組み合わせでも、書き方はいくつかあります。INTJ-O-H、INTJ-OH、INTJ OH、INTJ O H。どれも同じものを指します。このサイトではハイフンで3つに区切る INTJ-O-H の形に統一しています。

また、64タイプを名乗る診断は複数あり、追加の2軸に A / T と C / S を使うものもあります。記号が違うものどうしの結果は、そのままでは対応しません。他のサイトで出たコードをこのサイトで調べるときは、A / O・H / C の表記かどうかを確かめてください。

16タイプとの違い

4文字だけでは、同じINTJでも現れ方がまるで違う人が同じ箱に入ります。決めたあとに戻ってくるかどうか、人にまず開くかどうか。この2つは、日々の振る舞いにはっきり出るのに、4文字では区別されません。64タイプは、そこを2軸ぶん細かくしたものです。

たとえば INTJ-A-H と INTJ-O-C は、同じ INTJ でも、旗を掲げて人を巻き込む人と、ひとりで深く潜っていく人に分かれます。4タイプの違いを並べて見るのがいちばん早いです。

よくある質問

64タイプ性格診断とは何ですか？

広く知られている4文字の16タイプに、自分への確信を表すA / Oと、人への構えを表すH / Cの2つの軸を足したものです。16 × 2 × 2 で64通りになります。

A と O は何を表していますか？

自分への確信の軸です。A（確信）は自分の判断を疑わず、迷いが短いこと。O（揺らぎ）は決めたあとも考え直し、揺れながら精度を上げることを表します。Oは自信がないという意味ではありません。

H と C は何を表していますか？

人への構えの軸です。H（信頼）はまず信じて、自分から開いていくこと。C（慎重）は見きわめてから、距離を縮めることを表します。どちらが良いという軸ではありません。

INTJ-O-H と INTJ-OH は違うものですか？

同じものです。INTJ-O-H・INTJ-OH・INTJ OH・INTJ O H は、いずれも同じ組み合わせを指します。区切り方はサービスや記事によって異なります。

他のサイトで見た64タイプと文字が違います

64タイプを名乗る診断は複数あり、追加の2軸の記号が異なる場合があります。A / T と C / S を使うものもあります。64モンスターズは A / O と H / C を使っています。記号が違うものどうしの結果は、そのままでは対応しません。

MBTIの公式診断ですか？

MBTI®は The Myers-Briggs Company の登録商標です。64モンスターズは同社および関連団体とは一切関係がなく、公式のMBTI®アセスメントではありません。ここでいう4文字は、一般に広まった16タイプの表記を指しています。
