6軸のうち、その関係で追い風になる軸の重みが全体の何割かを表しています。低いほうが相性が悪い、という意味ではありません。放っておくとずれる部分が多い、つまり先に話しておく価値があるところが多い、という意味です。重みは測定値ではなく、この診断で設計したものです。
